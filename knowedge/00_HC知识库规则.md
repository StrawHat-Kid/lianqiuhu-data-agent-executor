# HC 纯问数知识库规则

> 本知识库由练秋湖 IOC 演示展示数据转换生成。所有数值均为**模拟演示数据**，不作为真实生产运行记录。

## 回答规则

1. 仅依据本目录事实数据和事件数据中明确存在的内容回答，不得编造缺失数据。
2. 每次给出业务数值时必须明确说明：**“以下基于模拟演示数据”**。
3. 数值回答应保留单位、分类条件和必要的时间条件。
4. 不得据此推断根因、处理人、工单结论或真实运行趋势。
5. `aggregation=累计` 与 `aggregation=当期` 不得混加或互相替代。
6. `data_flag=SYNTHETIC_DEMO_DO_NOT_USE_AS_FACT` 是强制属性。

## 时间槽位

源数据使用相对“系统时间槽位”，不是完整真实历史时间戳：

- `固定展示值`：固定展示指标。
- `系统时间月份-第 N 日`：系统当前月份中的第 N 日槽位。
- `系统时间年度-第 N 月`：系统当前年度中的第 N 月槽位。
- `系统时间日期-HH:MM:SS`：系统当前日期中的小时槽位。
- `系统时间事件-HH:MM:SS`：系统时间事件槽位。

用户使用“本月第 N 日 / 今年第 N 月 / 今天 HH 点”等相对表达时，可按对应槽位匹配。
若用户给出无法由知识库唯一映射的绝对历史日期，不得擅自映射，应说明当前数据按系统时间槽位组织。

## 多场景冲突

同一个自然语言指标可能对应多个 `scenario_id`：

- 值一致时可合并说明。
- 值不一致时不得任意选择；应列出候选值及对应 `scenario_id` / 上下文。
- `category`、`scenario_id`、同场景其他指标是重要区分条件。

已知示例：综合态势 / 人车数量统计中的“员工”“访客”存在两个不同演示场景值，必须避免单值武断回答。

## 生产知识文件

- `01_HC专题指标快照.csv`：固定展示指标。
- `02_HC月度指标.csv`：系统年度第 N 月指标。
- `03_HC能耗日度.csv`：系统月份第 N 日能耗指标。
- `04_HC运营日度.csv`：系统月份第 N 日运营指标。
- `05_HC小时指标.csv`：系统日期 HH:MM:SS 小时指标。
- `06_HC事件与告警.csv`：事件与告警记录。

事实数据使用 `fact_id`，事件数据使用 `event_id`。优先读取原始事实值，不从测试问答反向推算新事实。
